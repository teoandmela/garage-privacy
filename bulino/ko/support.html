안전이 먼저입니다

Bulino의 결과는 계산을 돕는 참고 자료이며 보증이 아닙니다. 가공에 대한 책임은 기계를 다루는 사람에게 있습니다. 항상 공구 제조사의 데이터와 기계의 안전 수칙을 따르세요. 확신이 없을 때는 더 보수적인 값으로 시작하세요.

자주 묻는 질문

공구 코드는 어떻게 읽나요?

계산 탭에서 코드 입력란 오른쪽의 카메라 아이콘을 누른 다음 사진 찍기 또는 사진 선택 버튼을 누르세요. 상자나 공구에 적힌 글자를 가까이에서, 똑바로, 밝은 곳에서 찍으세요.

Bulino가 읽은 내용 화면을 보여 줍니다. 확인하고 필요하면 고친 다음 이 코드 사용 버튼을 누르세요. 앱은 사용자가 확인한 코드만 사용합니다. 예를 들어 인서트 코드(CNMG 120408-PM), 나사(M10, M12x1.5, 1/4-20 UNC, G 1/2), 드릴과 엔드밀의 표기(Ø 8.5 HM, D12 Z3 HM)를 읽을 수 있습니다.

잘못 읽거나 코드를 찾지 못하면 어떻게 하나요?

가까이 다가가고, 조명을 밝게 하고, 반사를 피해서 다시 시도하세요. 또는 입력란에 코드를 직접 입력하세요. 계산은 똑같이 작동합니다. Bulino가 코드를 인식하지 못하면 아래 입력란에 적은 정보로 계산합니다.

왜 ‘시작 조건’인가요?

Bulino는 공개된 공식과, 공구 제조사의 가이드를 비교해 우리가 정리한 범위로 계산합니다. 하지만 기계, 클램핑, 공구, 소재는 저마다 다릅니다. 이 값에서 시작해 칩, 소리, 가공면을 보면서 조정하세요. 사용하는 공구 제조사의 카탈로그와 다르면 카탈로그를 따르세요.

기계의 한계는 어떻게 반영되나요?

기계 탭에서 새 기계 버튼을 누르고 최대 회전수, 주축 출력 값을 입력하세요. 알고 있다면 최소 회전수, 최대 토크, 최대 절삭 이송속도, 선반의 경우 G96 회전수 제한, 그리고 강성 항목도 입력하세요. Bulino는 값을 이 한계 안에서 유지합니다. 기계를 등록하지 않으면 회전수와 출력은 반영되지 않습니다.

밀리미터와 인치 중 무엇을 쓰나요?

처음에는 휴대폰의 국가에 맞춰 Bulino가 선택합니다. 설정 › 단위 화면에서 언제든지 밀리미터 또는 인치 단위로 바꿀 수 있습니다.

레시피는 어떻게 쓰나요?

계산한 뒤 레시피 저장 버튼을 누르면 결과, 가공 수, 메모, 사진을 남길 수 있습니다. 다음에 같은 소재나 같은 공구로 비슷한 가공을 할 때 Bulino가 잘 됐던 값 제안을 보여 줍니다. 이 값 사용 버튼을 누르면 잘 됐던 값을 오늘의 기계와 지름에 맞춰 다시 사용할 수 있습니다. 레시피 탭에서는 소재, 공구, 기계, 메모로 찾을 수 있습니다.

가공 수 카운터는 어디에 쓰나요?

현장 모드에서는 값이 크게 보이고 화면이 켜진 채로 유지되며 가공 수를 셀 수 있습니다. 코너를 바꾸면 코너를 바꿨어요 버튼을 누르세요. Bulino가 코너 하나로 몇 개를 가공하는지 배워서 다음 예측에 사용합니다.

문제가 있어요 버튼은 무엇을 하나요?

계산한 뒤 문제가 있어요 버튼을 누르고 보이는 증상(예: 떨림)을 고르세요. Bulino가 가능한 원인과 수정된 값을 보여 주고, 적용 버튼으로 바로 적용할 수 있습니다.

데이터는 어디에 저장되나요?

이 휴대폰의 Bulino 안에만 저장됩니다. 계정도 온라인 사본도 없어서 우리는 데이터를 볼 수 없고 복구할 수도 없습니다. 자세한 내용: 개인정보 처리방침

휴대폰을 바꾸면 어떻게 되나요?

Bulino에는 계정도 동기화도 없습니다. 데이터는 시스템이 백업이나 기기 간 전송으로 옮겨 줄 때만 새 휴대폰으로 옮겨질 수 있습니다(iPhone과 iPad는 iCloud, Android는 Google 백업). Apple과 Google이 관리하는 부분이라 우리가 보장할 수는 없습니다. iPhone과 Android 사이에서는 데이터가 옮겨지지 않으니, 바꾸기 전에 중요한 레시피를 적어 두세요.

언어는 어떻게 바꾸나요?

Bulino는 휴대폰의 언어를 사용합니다. 설정 › 언어 화면의 버튼(휴대폰 설정에서 바꾸세요)을 누르면 휴대폰 설정이 열립니다.

모든 데이터를 삭제하려면 어떻게 하나요?

위쪽의 톱니바퀴 아이콘을 눌러 설정 화면을 열고 모든 데이터 삭제 버튼을 누른 다음 모두 삭제 버튼으로 확인하세요. 이 휴대폰에서 레시피, 사진, 기계, 가공 수, 설정이 지워지며 되돌릴 수 없습니다.
